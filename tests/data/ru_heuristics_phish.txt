# PHISH — look-alike hosts the local heuristics must keep catching.
#
# The counterpart of ru_heuristics_legit.txt: the same offline scoring
# (calculate_score() on the bare host), used to prove a false-positive fix
# does not cost detections. "Caught" = the host scores above 'safe'.
#
# These hosts are CONSTRUCTED, not harvested: each follows a pattern from
# live Russian-language phishing (brand typos, digit / Cyrillic homoglyphs,
# brand + lure-word combos on cheap TLDs, the brand's real domain used as a
# subdomain of the attacker's, and brand names registered under regional
# public suffixes — the CT log for nov.ru alone lists vk.nov.ru, mts.nov.ru,
# ok.nov.ru and kinopoisk.nov.ru). Most do not exist; the scorer only reads
# the name. Global brands are included as a control for the rules that
# already know them. The exceptions are 'reported' (named in a fraud
# report) and 'observed' (found live, with what was on the page).
#
# Format — one host per line, fields separated by " | ":
#   host     punycode for IDN (the scorer's input form)
#   pattern  typosquat      character-level typo of the brand's name
#            homoglyph      digit / Cyrillic / multi-glyph look-alike
#            combosquat     brand + lure word, often on a cheap TLD
#            subdomain      brand's real domain as a subdomain of another
#            zone           brand look-alike registered under a regional
#                           public suffix (spb.ru, msk.ru, nov.ru, com.ru …)
#            fake_tld       a TLD bought as the name under an open zone
#                           (com.msk.ru, ru.msk.ru, gov.msk.ru are private
#                           persons' names), so vk.com.msk.ru reads as vk.com
#            short_brand    a 3-4 letter global brand under another TLD or
#                           with look-alike characters (control)
#            reported       a phishing domain a fraud report names verbatim
#                           (F6: cdek.nu …, yandex-doctavym.website …)
#            observed       a live look-alike of a Russian brand found on
#                           2026-09-27 by resolving every registered
#                           <brand>.<TLD>, one-edit .ru and combo name; the
#                           note says what was on it
#            ru_com         the brand's .ru address bought under ru.com or
#                           ru.net, zones anyone can register in
#            known_miss     a typo the rule deliberately gives up — a 4-letter
#                           omission of a 5-letter brand, two substitutions in
#                           under 8 letters, a word api/services/ru_lures.py
#                           leaves out — listed so its loss is counted
#   target   the brand's real domain
#   note     Unicode form of an IDN, or what the pattern does
# '#' starts a comment; blank lines are ignored.
