# Экран подтверждения подписки — версия ru/v1

Этот текст показывается ДО запроса SMS-кода (ст. 44 п. 5 «О связи»). Его
sha256 сохраняется в журнале согласий вместе с показанной ценой, чтобы мы
могли доказать, что именно видел человек, когда согласился.

Изменение любого слова = новая версия файла (v2.md) и новое значение
`BILLING_CONSENT_DOC_VERSION`. Приложение передаёт версию, которую показало;
сервер принимает только текущую.

деньги «в минус» и не используем отложенный платёж оператора.
