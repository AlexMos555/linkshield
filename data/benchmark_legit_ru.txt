# Real Russian sites OUTSIDE our allowlist: the weekly benchmark's
# false-positive sample (scripts/eval_fresh_urls.py, the default legit source).
#
# Why a hand-built list: the public check answers every Tranco top-100k domain
# "safe" without analysing it (api.services.scoring.is_trusted_top_domain), so
# a legitimate sample drawn from Tranco measures nothing — the benchmark never
# published a false-positive rate for that reason. The people we protect visit
# their region's and city's administration, a university, a local bank, shop,
# museum or church, a .рф municipal page: sites no global top list ranks. The
# 2026-09-25 full check found 6 of 12 such sites called "Dangerous".
#
# Format — one site per line, fields separated by " | ":
#   host          punycode, no "www." — exactly what the benchmark sends
#   category      regional_gov, city, university, rf, bank, business, museum, theatre
#   reachability  from outside Russia on 2026-09-27: reachable-abroad (served
#                 its own page) or blocked-abroad (timeout, 403 or an anti-bot
#                 wall). Our server is abroad too; blocked-abroad is the case
#                 the report found scored as "no HTTPS" → "Dangerous".
#   source        the Wikidata item whose official website (P856) is this host
#                 (Wikidata is CC0), or the report that named the site
#   name          the item's label (and the Unicode form of a .рф host)
# '#' starts a comment; blank lines are ignored.
#
# How it was built (2026-09-27):
#   1. Wikidata SPARQL, official websites (P856) of: federal subjects of Russia
#      (Q43263), towns/cities in Russia over 50,000 people (Q7930989), Russian
#      universities (Q3918), banks (Q22687) and businesses (Q4830453) not
#      marked dissolved, museums (Q33506), theatres (Q24354), and any Russian
#      item whose site is on .рф.
#   2. Kept hosts under .ru / .su / .рф that is_trusted_top_domain does NOT
#      trust: 4,002 candidates. A fixed-seed sample per category was taken.
#   3. Each host resolved (A record via 1.1.1.1) and its home page fetched.
#   4. Reviewed by hand. Dropped every host whose page is no longer the
#      entity's: 7 casino mirrors on lapsed domains (a town, two rural
#      administrations, two museums, a puppet theatre, a cathedral), for-sale
#      and parked pages,
#      hosting placeholders, unrelated redirects, 404/5xx, "site moved" stubs.
#      A host unreachable from abroad was kept only for a state body (region,
#      city, municipality, university), whose domain is not left to lapse; a
#      business that did not answer was dropped — nothing confirmed it.
#   5. Added the five sites the 2026-09-25 report named (bankspb.ru,
#      президент.рф, мойбизнес.рф, разговорыоважном.рф, rosreestr.gov.ru).
#
# Re-check before trusting a refresh: python3 scripts/eval_fresh_urls.py
# --verify-legit-sample (every host resolves and is outside the allowlist).
# tests/test_eval_fresh_urls.py pins the format, the size, and the allowlist
# rule in CI. Remove a site that stops being its entity; never add one
# because it scores well.
