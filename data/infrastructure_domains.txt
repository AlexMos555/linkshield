# Internet infrastructure the DNS blocklist must never darken.
#
# One registrable domain per line; '#' starts a comment. First-party and
# hand-curated (2026-10-23): the DNS root and TLD operators, the big DNS
# hosts, certificate authorities' OCSP / CRL names, and the CDN, push,
# update, telemetry and media names that phones and their apps resolve
# constantly — written down from the operators' own documentation
# (network-requirements and endpoint lists, nameserver names), not taken
# from any ranked list.
#
# Why it exists: until 2026-10-23 the popularity veto was Tranco's top-10k,
# and Tranco averages DNS-traffic lists (Cisco Umbrella, Cloudflare Radar)
# that rank such names high. The licensed ranking that replaced it
# (scripts/build_top_domains.py) counts links (Majestic) and page loads
# (Chrome UX Report): nobody links to or opens gtld-servers.net or
# nflxvideo.net, so they are not in it. A bad publish that listed one would
# break apps for every DNS user.
#
# Read by:
#   scripts/build_mobile_assets.py      → popular_veto.txt on the phone
#   scripts/refresh_dangerous_domains.py → the publisher's popular guard
#                                          (never block or promote these)
#
# NOT an allowlist: these names get no 'safe' verdict from it. Never add a
# host where users publish content (googleusercontent.com, sharepoint.com,
# s3 buckets): blocking a tenant there must stay possible.
